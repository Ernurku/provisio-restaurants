# Provisio

Provisio — веб-приложение для ресторанного бэк-офиса: расчёт себестоимости рецептов, меню, поставщики и закупки.
Provisio is a restaurant back-office web app for recipe costing, menu pricing, suppliers and purchasing.

## Проблема

Рестораны и кафе чаще всего считают себестоимость блюд вручную — в Excel или на бумаге. Из-за этого сложно быстро увидеть реальную маржу конкретного блюда, сравнить цены разных поставщиков по одному и тому же ингредиенту и понять, сколько сырья нужно закупить под ожидаемые продажи. Provisio переносит этот расчёт в единое приложение и пересчитывает его автоматически при любом изменении цены или рецепта.

## Что делает

- Ведёт справочник ингредиентов: единицы измерения, вес, % отхода (EP%), конверсии единиц.
- Хранит поставщиков и их цены на ингредиенты; при расчёте автоматически берёт наименьшую цену за грамм среди поставщиков.
- Считает себестоимость рецепта по цепочке: цена поставщика → цена ингредиента с поправкой на EP% → себестоимость рецепта.
- Считает маржу и прибыль позиции меню на основе себестоимости рецепта и цены продажи.
- Формирует список закупок (Purchasing) на основе ожидаемых продаж.
- Показывает сводные показатели на дашборде.
- Поддерживает мультитенантность и командный доступ на уровне базы данных (Row Level Security в Supabase).
- Тёмная тема и несколько цветовых палитр интерфейса.

## Как работает

1. Пользователь заводит ингредиенты и поставщиков с ценами в соответствующих разделах.
2. Собирает рецепт из ингредиентов — приложение автоматически подтягивает минимальную цену за грамм от поставщиков.
3. Движок расчёта (`ReactiveEngine`) на лету пересчитывает себестоимость рецепта с учётом единиц измерения и % выхода/отхода.
4. Рецепт добавляется в меню — считается маржа и прибыль блюда с учётом цены продажи.
5. Раздел Purchasing формирует список необходимых закупок исходя из ожидаемых продаж блюд.
6. Дашборд показывает сводку по ключевым показателям.

## Стек технологий

- **Frontend** — HTML / CSS / vanilla JavaScript, одностраничное приложение без сборки и фреймворков.
- **База данных и бэкенд** — Supabase (PostgreSQL + Row Level Security), авторизация через Supabase Auth.
- **Серверные функции** — Vercel `/api` (интеграции, например с Frontpad).
- **Legacy-интеграция** — вебхук n8n для AI-парсинга и приглашений в команду (частично не поддерживается).

## Статус проекта

В активной разработке (MVP). Работает: ведение ингредиентов и поставщиков, расчёт себестоимости рецептов и меню в интерфейсе, мультитенантность через RLS. Известные незакрытые проблемы задокументированы в [ДИАГНОСТИКА.md](ДИАГНОСТИКА.md) — в частности, расхождение имён колонок между отдельными модулями и схемой БД (`calculated_cost`/`cost`, `sale_price`/`price` и т.п.) и не до конца рабочая связь «Меню → Рецепт». Раздел Team/Inventory/Orders (Phase 2) отложен — код лежит в `/archive` и связанных модулях, вкладки в интерфейсе скрыты.

## Файлы в репозитории

- `admin.html`, `login.html`, `register.html` — страницы приложения (админ-панель, вход, регистрация).
- `css/admin/` — стили: переменные темы, layout, компоненты, стили отдельных вкладок.
- `js/admin/` — JS-модули: `admin-core.js` (ядро и состояние), `admin-db.js` (CRUD в Supabase), `admin-reactive.js` (движок расчёта себестоимости), `admin-ui.js` (навигация/UI), а также модули вкладок ingredients, suppliers, recipes, menu, calculator, purchasing, dashboard, settings, tutorial.
- `js/admin/admin-inventory.js`, `admin-orders.js`, `admin-team.js` — модули Phase 2 (загружаются, но соответствующие вкладки в интерфейсе скрыты).
- `api/` — серверные функции Vercel (интеграции, например Frontpad).
- `supabase_schema_new.sql` — актуальная схема базы данных (v8).
- `supabase_migration_v8_purchasing.sql`, `supabase_migration_v9_tutorial.sql`, `supabase_migration_v10_sklad_integrations.sql` — миграции поверх v8.
- `ДИАГНОСТИКА.md` — список известных багов и несоответствий между кодом и схемой БД.
- `archive/` — маркетинговые страницы (лендинг, блог, документация) и другие отложенные материалы, вне ядра приложения.
- `vercel.json` — конфигурация деплоя на Vercel.
