Не подключено
Как подключить:
  1. Нажмите «Подключить» — появится ссылка для Frontpad.
  2. Откройте в Frontpad: Настройки → Общие → API.
  3. Вставьте туда ссылку и свой код доступа Frontpad.
  4. Вернитесь сюда и нажмите «Проверить подключение».
